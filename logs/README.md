# ACME Certificate Manager - Logging Configuration

This directory contains application logs generated by the Winston logger.

## Log Files

- `error.log` - Contains only error-level logs
- `combined.log` - Contains all logs (info, warn, error, debug)

## Configuration

Logging behavior can be configured via environment variables in the backend `.env` file:

### Environment Variables

```bash
# Logging level (default: info)
# Options: error, warn, info, debug, verbose
LOG_LEVEL=info

# Directory for log files (default: ../logs relative to backend)
LOG_DIR=/var/log/acme-certificates-manager

# Enable/disable console logging (default: true in development)
ENABLE_CONSOLE_LOGS=true

# Enable/disable file logging (default: true)
ENABLE_FILE_LOGS=true
```

## Logging Strategy

### Development Mode
- **Console**: ✅ Enabled (colored output with timestamps)
- **File**: ✅ Enabled
- **SSE**: ✅ Always enabled when client connects

### Production Mode
- **Console**: ❌ Disabled (set `ENABLE_CONSOLE_LOGS=false`)
- **File**: ✅ Enabled
- **SSE**: ✅ Always enabled when client connects

## Log Rotation

For production deployments, consider using log rotation tools:

### Linux (logrotate)

Create `/etc/logrotate.d/acme-certificates-manager`:

```
/var/log/acme-certificates-manager/*.log {
    daily
    rotate 14
    compress
    delaycompress
    notifempty
    missingok
    create 0640 acme-certificates-manager acme-certificates-manager
}
```

### PM2 (Node.js Process Manager)

PM2 automatically handles log rotation:

```json
{
  "apps": [{
    "name": "acme-certificates-manager",
    "script": "dist/server.js",
    "max_memory_restart": "500M",
    "log_date_format": "YYYY-MM-DD HH:mm:ss Z",
    "error_file": "/var/log/acme-certificates-manager/pm2-error.log",
    "out_file": "/var/log/acme-certificates-manager/pm2-out.log",
    "merge_logs": true
  }]
}
```

## Monitoring

### View Real-time Logs

```bash
# All logs
tail -f logs/combined.log

# Only errors
tail -f logs/error.log

# Filter by context
tail -f logs/combined.log | grep "ACME"
```

### Log Analysis

```bash
# Count errors today
grep "$(date +%Y-%m-%d)" logs/error.log | wc -l

# Find certificate issuance failures
grep "Certificate.*Error" logs/combined.log

# Analyze ACME operations
grep "\[ACME\]" logs/combined.log | tail -100
```

## Security Notes

- Log files may contain sensitive information (domain names, email addresses)
- Ensure proper file permissions: `chmod 640 logs/*.log`
- Never commit log files to version control
- Regularly clean old logs to save disk space
- Consider encrypting logs in compliance-sensitive environments
